
# PlotPickle AI readiness review

## Strong foundations already present

- Provider-independent text and image adapters, including OpenAI-compatible and local options.
- Local-first project ownership with no required PlotPickle cloud account.
- Explicit prepare → compare → approve/discard boundaries.
- Canonical project context instead of disconnected prompt documents.
- Prompt, model, human contribution and retained-output provenance.
- Character voiceprints, visual continuity locks and bounded specialist labs.
- GitHub pull-request approval for changes from many local PlotPickle servers.

## Highest-value AI gaps still remaining

1. **Field- and scene-level semantic merge** for two proposals that edit different parts of one `.ppf`.
2. **Private retrieval index** over Canon Binder, research and approved project history.
3. **Cost and token controls** by provider, operation, project and collaborator.
4. **Privacy/redaction profiles** before sending screenplay context to a remote model.
5. **Prompt-injection and source-trust defenses** for imported research and web material.
6. **Capability negotiation** so PlotPickle knows which model supports text, images, tools or long context.
7. **Multi-model comparison** with the writer selecting the retained answer and provenance.
8. **Background job queue** for long image, video, transcription and analysis tasks.
9. **Evaluation fixtures** that test whether AI suggestions preserve canon, voice and screenplay format.
10. **AI change summaries** attached automatically to collaboration pull requests.

PlotPickle is not missing a general chatbot. Its next AI maturity step is safer context retrieval, measurable quality, controlled cost and conflict-aware collaboration.
