RECOMMENDED USE
---------------
- Use the horizontal transparent logo in the website header and footer.
- Use favicon/favicon.ico for the standard browser favicon.
- Use plotpickle-icon-192.png and plotpickle-icon-512.png for web-app icons.
- Use apple-touch-icon-180.png for Apple touch devices.
- Use the original stacked logo for presentations, download pages and social posts.
- Use the transparent stacked logo for splash screens and branded artwork.

The transparent dark-teal wordmarks are designed for light or ice-colored
backgrounds. Use the icon-only mark where space is limited.
