Foundations welcome acceptance

PLAN -> Foundations opens on a welcome choice unless a direct lesson URL is requested.

Primary path
- Load a PlotPickle .ppf as read-only story evidence.
- Auto-complete currently empty Foundations answers only.
- Preserve existing Foundations answers.
- Build and save the Foundations Brief.
- Do not mutate LEARN, later PLAN areas, blocks, screenplay, BUILD, STORYBOARD, PREVIS, WRITE, EDIT, FEEDBACK, REFINE or REPORTS.

Secondary path
- Start or continue the eleven Foundations lessons manually.
- Clicking a lesson opens the normal lesson editor.
- The lesson editor provides a clear return to the Foundations welcome screen.
