# Issue #444 Phase A — PlotPickle Studio Dashboard

Approved before implementation.

## Wireframe intent

The Dashboard is the first in-app screen after Enter. It continues the splash aesthetic with a full-width matte-black desktop canvas, warm-gold accents, editorial/typewriter hierarchy, large poster-led project cards, and minimal application chrome.

## Primary layout

1. PlotPickle Studio title and short story-first orientation.
2. Primary actions: New Project and Import Project.
3. Story Library with large cinematic poster artwork.
4. Afterglow shown as an optional read-only example with an explicit Load action; never auto-loaded by the Dashboard.
5. Current/local story card when a story exists.
6. First approved/generated setup image becomes the project poster artwork and visual identity.
7. Current story continuation panel.
8. Persistent 4 Acts / 24 Blocks / 96 mini-blocks architecture context.
9. Complete module workflow strip: Dashboard, Learn, Plan, Storyboard, Write, Edit, Graphic Novel, Build, Feedback, Refine, Reports.
10. Settings/creative tooling remain secondary and outside the story workflow.

## Flow

Splash -> Dashboard -> choose/open story -> Plan or next recommended creative module.

The same story identity and PPF context continue into every later module. No parallel story copy is created by navigation.

## Visual acceptance

Rendered desktop evidence must visibly resemble the approved wireframe: full-screen dark Studio, warm-gold hierarchy, poster-led story selection, restrained text density, and obvious 24/96 story architecture.
