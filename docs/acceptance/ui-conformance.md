# UI Conformance Acceptance

PlotPickle UI conformance is green only when the rendered Skin surfaces obey the active Skin contract and the existing screenshot evidence remains available.

Required evidence:

- WebMCP can navigate the bounded Skin surfaces without mutation authority.
- Every governed visible component is inventoried, not just one sampled control.
- Typography and square Skin V1 geometry are checked across the full inventory.
- Violations report surface, role, stable identity, property, actual, expected and source token/rule.
- Candidate screenshots remain captured for the repository-owned baseline comparison.
- Visual findings are safe to include in focused UAT reports and contain no story text, prompts, reasoning or credentials.
- Pi/Cline may receive those findings only through the existing bounded repair workflow.

The UI/UX standard is design intent, global design tokens are semantic primitives, and the active Skin definition is the rendered presentation mapping.
