# Dashboard and Settings separation

The Dashboard is a read-only status centre. It uses red, yellow and green states and links to exact Settings sections. It contains no configuration controls.

Each configurable component owns an independent Settings section with a stable section ID, status, configuration, test/update action, result, and repair guidance.

Initial sections: Ollama, OpenAI, MiniMax, ComfyUI, GitHub, Buzz, Google Calendar & Meet, Plugins & Connections, Storage & Backups, and Privacy & Credentials.
