# Developer brief: evidence assessed Outline to Storyboard handoff

## Human intent

Outline describes the written story. For each of the 24 Blocks and four Mini-Blocks, the system should examine the imported screenplay and saved PPF planning and explain specific structural and character evidence or gaps. Repeated unresolved fixture wording, passage counts, and human-selected dropdowns do not amount to an assessment. Storyboard then uses those same stable addresses for visual scenes and anchors. The 24/96 mathematics measures location and traceability, not dramatic quality or a fixed frame quota.

## Existing owners and boundary

Reuse imported screenplay evidence, Story Matrix, character truth, the Story Architect agent via the existing runtime, Outline readiness, and Storyboard anchor addresses. Keep imported text and reviewed human canon intact. Agent findings are provisional; passage IDs must resolve to the supplied screenplay sample. A visual cue is a grounded question, not an accepted shot or generated image. A stale finding must not be shown as current after relevant text or plan changes.

## Acceptance

1. A writer can request a Block or Act assessment without selecting structural or character states manually; each result cites allowed screenplay passages and identifies a concrete uncertainty when necessary.
2. Outline shows the evidence and distinguishes pending, supported, gap, and review conditions without treating mapped text density as proof.
3. The written script view and Storyboard carry the same Block and Mini-Block addresses and provisional visual questions; Storyboard displays the Outline gap at that address.
4. Source edits invalidate the displayed agent finding; existing reviewed findings and screenplay content remain intact.

## Verification

Focused Outline/fixture/character regressions, focused UAT contracts, production build, convergence and exact-head CI. The connected model's actual judgment remains an empirical result: tests validate evidence and authority boundaries, not that any particular creative conclusion is correct.
