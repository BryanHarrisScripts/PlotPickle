## Product integration

### Project Overview

Afterglow projects show a Legacy Afterglow Visuals gallery with overview boards and counts for retained, mapped, proposed, unresolved and missing later-Block coverage.

### Visual Bible and Pitch

Visual Bible now distinguishes three sources:

1. current project-owned mood-board assets;
2. legacy Afterglow project visuals;
3. the general PlotPickle Visual Reference Library.

Legacy visuals can be prepared as project references, Block-cover approvals, pitch references or retired assets. Every choice enters the existing specialist review gate before it is applied or recorded.

### Storyboard

### Learning

## Approval and provenance boundaries

- Bundled image bytes are not duplicated into schema 1.7 project files.
- No visual is approved solely because it is present in the bundle.
- Legacy visual decisions are stored through existing specialist-pass revision records.
- Source filename and SHA travel with the decision record.
- A legacy source selection is not classified as a new AI generation event.
- Unknown historical provider, model or prompt information is not invented.
- Public release still requires image-specific rights and third-party-content review.
