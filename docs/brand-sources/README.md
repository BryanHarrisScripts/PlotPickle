# PlotPickle v2 brand source

The checked-in master images in this directory are the immutable local source for the updated Sage Brinewick portrait and PlotPickle ouroboros/pen mark. They were derived from `plotpickle-sage-logo-reference-2026-08-13.png`, supplied by the project owner, with the built-in image-generation editor.

Runtime assets are generated locally by:

```powershell
python scripts/build-plotpickle-brand-assets.py
```

The application uses a text-free emblem and renders the PlotPickle name as HTML. This prevents distorted lettering at small sizes and keeps the product name accessible. The supplied combined reference is retained here so the visual lineage is not lost.
