# Actionable Afterglow saved-record review

The Human completed 90 creative selections but cannot consolidate because remaining image approval, metadata, and structural differences are read-only. Repeated historical thumbnails make it hard to understand what is being reviewed.

## Required behavior

Each remaining saved record has Save to master and Not required controls, with full values, source dates, recorded approval, and one displayed version per record. Identical saved versions are grouped. Existing creative selections remain in the same encrypted review draft. An explicit choice selects a complete authenticated source record; it never fabricates an approval. Not required excludes entities/images from the new master and retains the packaged value for scalar changes. Source snapshots are never deleted.

The server independently reconstructs the same source inventory and choice indices. Unknown choices, changed source digests, invalid saved acceptance, missing retained media, and removed originals of retained derived images still block. Explicitly excluded or superseded URLs are not required to exist, while all retained URLs require independent server file verification and encrypted readback. Character structural choices select a complete saved package and take precedence over earlier per-image selections only for that explicitly selected character. Unrelated character locks remain protected.

Export the exact verified master from its receipt ID for subsequent promotion to the official example. This change must not publish the synthetic verification profile or claim the Human's unavailable local master was promoted.

## Validation

Focused record-selection and existing Afterglow regressions, focused UAT contracts, production build, convergence, exact-head Architecture Verification, and actual Windows rendered proof. The rendered proof must select a saved approved image against a draft version, leave out an optional poster, reopen the durable review, save through the authenticated server, and inspect the actual master export. No provider inference or Human account is used.
