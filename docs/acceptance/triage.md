# Acceptance triage

Priority order after each agent run:

1. FAIL: broken navigation, data/context loss, crashes, inaccessible actions, persistence failures, unsafe behavior.
2. WARN: confusing workflow, weak discoverability, inconsistent visual hierarchy, misleading status/recovery language.
3. PASS: retain as regression evidence; do not create repair work.

Do not expand scope into unrelated features while acceptance defects remain open.
