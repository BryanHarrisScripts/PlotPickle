# Phase 6 acceptance checklist

- [ ] Offline proposal operations queue without losing local work.
- [ ] Retry is explicit and safe after connectivity returns.
- [ ] GitHub App token renewal preserves the selected story project.
- [ ] Repository rename or move can be reconnected without editing project files manually.
- [ ] Deleted branches produce guided recovery instead of silent recreation or force-push.
- [ ] Conflicts identify the expected and current approved commit plus affected canonical paths.
- [ ] Audit history contains decisions and retry outcomes but no credentials.
- [ ] Sandbox collaboration tests cover contributor and Project Lead flows.
- [ ] Windows, macOS and Linux release checks pass after implementation.
