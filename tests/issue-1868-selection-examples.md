# Cinematography grammar selection examples

These examples are test notes, not prompt templates.

- `isolated + small in frame + slow reveal` should prefer subject-small framing, weighted negative space and slow reveal when medium is video.
- `intimate + pressure + move closer` should prefer face-dominant framing and push-attention movement.
- `push in + pull back` should not emit both mutually conflicting camera directions in the same bounded selection.
- a still-image request should never receive camera-movement, edit-transition or sound-atmosphere primitives.
