# Board A — Matrix Interface Blueprint

Prompt ID: `matrix-board-a-interface-blueprint-v1`  
Master prompt: `matrix-master-v1`  
Version: `1.0.0`

## Purpose

Generate one landscape PlotPickle Matrix reference board that explains **how a Matrix screen is composed**. This is a design-reference artifact, not a production screenshot.

Apply every invariant in the Matrix Master Generation Prompt, then emphasize:

- standard header / title region;
- master navigation;
- main viewport;
- primary button / primary action;
- status bar;
- compact list-item patterns;
- return/back treatment;
- keyboard-shortcut presentation;
- page hierarchy;
- major spacing, density and region relationships;
- clear focused and selected examples inside the composition.

## Board composition

Show one representative Matrix surface plus a small annotated anatomy key. Use generic fictional content. Keep one dominant work area and avoid decorative frame nesting.

Suggested annotation vocabulary:

`SURFACE` → `HEADER` / `MASTER NAVIGATION` / `MAIN VIEWPORT` / `PRIMARY ACTION` / `STATUS BAR`

Within the viewport, show at least:

- one normal list item;
- one selected list item;
- one keyboard-focused control;
- one disabled action;
- one return/back control;
- one visible shortcut label.

## Required visual intent

Use black / white / restrained Matrix-green semantics and compact square geometry. The hierarchy should remain legible at a glance, with thin borders, disciplined spacing and strong text alignment.

Do not make the board look like Adobe Premiere, a terminal emulator screenshot or a generic cyberpunk dashboard. It should read as PlotPickle Matrix design intent.

## Output boundary

The generated board is `candidate-reference` until Human approval. It may guide the later Experience Surface Contract but must not be used as a production screenshot or locked baseline.
