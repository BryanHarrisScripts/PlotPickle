# Story Architect protected host controller

Issue #2711; parent #2707. Builds on the tested, unmerged worker/input PR #2712.

## Bounded implementation scope

Implement the authenticated host kernel beneath the existing `build/projects/` owner. Reuse existing responsibility runs, profile auth/vault checks, encrypted project-domain objects, shared Outline requests and canonical citation validation. The host supplies execution selection, grants, conservative token/cost quotes and limits; the browser cannot supply authority or credentials. Admission creates only a protected record. Only an explicit authenticated Human activation creates an in-memory execution lease. Construction, progress reads and reopen perform no inference.

The record contains the approved profile/project/material/compute/agent scope, bounded ordered Blocks, the existing creative responsibility run, durable attempt reservations and validated advisory proposals. Each worker call first persists its attempt and full token/cloud-cost reservation. Reservations remain upper bounds, including interrupted calls, unknown usage and retries; resume cannot replenish attempts or present missing usage as free work. A cloud route without a conservative host quote fails closed. Quotes must cover the full request, output and worker-runtime retry policy. This kernel does not invent provider pricing or infer that an OpenAI-compatible endpoint is free.

Before work and result admission, recheck the session, unlocked vault, approved active project, strong material identity, exact selected compute and grants, run state and remaining budget. Preserve the final permitted attempt's result without allowing another call. Serialize protected-record mutations but release the mutex during inference so cancellation remains responsive. Duplicate simultaneous worker callbacks cannot issue a second call. Profile cleanup and controller shutdown revoke leases and abort workers; Pi invocation cancellation also reaches the worker. Cancellation is persisted before acknowledgement and denies late findings. Reuse a previously protected step proposal when Pi did not yet commit its checkpoint; do not repeat its provider call.

All findings remain non-canonical. The controller never saves accepted project material. After the trusted adapter verifies Pi completion, finish moves the existing run to waiting-for-writer, not accepted/completed canon.
