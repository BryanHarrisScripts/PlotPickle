# #3411 — Project inspection inside the user's execution environment

The owner wants a cloud-first plugin available across plans, prioritizing Go
and Plus, with no local Windows dependency or publisher-funded runtime. Sites
is optional. Assess the smallest useful serverless implementation first.

## Scope

Provide a private skills-only plugin reading an explicitly supplied existing
PPF export. Bundle the existing project parser, canonical structure projection
and Storyboard observer into one dependency-free runtime script. Reuse the
same structure and Save/Lock interpretation as the application. Treat the
user's permitted file as the source, not a Factory-authenticated live vault.

The source and reproducible build belong under
tools/agent-plugins/plotpickle-story-reader. The generated bundle is ignored
in Git and included in the private plugin package. Do not include real project
data, owner credentials, a fixed Library identity, server URL or app binding.
Include the repository license for bundled source.

## Acceptance

1. Validate identity, revision, exact file digest and complete raw structure
   before reporting derived project evidence. No normalization-based false green.
2. Recover the canonical 4 Acts / 12 Sequences / 24 Blocks / 96 Mini-Blocks /
   25 planned Shot slots per Mini-Block from existing model owners.
3. Page retained screenplay source in order and disclose retained truncation.
4. Read exported candidate Save/Lock metadata without verifying referenced
   media bytes or changing the source file. Reject stale/malformed inputs.
5. Repeat the same inspection in a fresh process and compare output/digest.
6. Validate and save a private usable plugin. Preserve its actual diagnostics
   and identity; do not confuse account creation with host invocation proof.

## Limits

Synthetic fixture and fresh-process execution do not prove actual Brotherly
Love readback, a new conversation's file access, hosted plan billing, Go
availability or public release. The user must have cloud execution and file
access on the selected surface; the package cannot grant them. Private plugin
creation must not be reported as installation or verified Go/Plus operation.

This phase does not mutate projects, replace the profile authentication system,
run unattended, verify media bytes, register artwork or create a second store.
Remote MCP and hosted user storage are not required to inspect an authorized
portable export, but the complete production/persistence workflow remains open.
