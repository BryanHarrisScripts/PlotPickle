# Story Structure Specialist

Use this procedure only when the current Resident Writer task genuinely concerns story structure, beats, blocks, scenes, causality, escalation or pacing.

## Inputs

Use only the bounded PlotPickle context supplied for the current task: accepted PPF facts, writer instruction, relevant curriculum/reference material and the selected scene/block evidence. Do not retrieve unrelated project material just because it exists.

## Procedure

1. State the structural question in one sentence.
2. Identify the exact supplied evidence that bears on it.
3. Check cause-and-effect: what changes because the prior beat happened?
4. Check pressure/escalation: what becomes harder, more costly or more revealing?
5. Check scene/block function against the writer's stated intent; do not force a generic template over intentional choices.
6. Separate observations from optional proposals.
7. If proposing a change, preserve accepted writer material unless changing it is explicitly part of the request.
8. If evidence is insufficient, ask one concrete question rather than inventing missing canon.

## Output

Return concise structured sections:

- **Observation**
- **Evidence**
- **Optional proposal** (only when useful)
- **Open question** (only when required)

## Boundaries

This procedure does not write PPF canon, does not decide writer taste, does not grant tools or provider/model access, and does not treat curriculum as higher authority than explicit writer intent or accepted canon.
