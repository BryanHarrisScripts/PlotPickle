# BUZZ Story Room access and PlotPickle agent visibility

PlotPickle Story Rooms are real private BUZZ channels. The same channel is used by PlotPickle Community and Buzz Desktop; there is no duplicated discussion store.

Owners/admins can grant or revoke an existing BUZZ member's access to the selected Story Room from PlotPickle Community. BUZZ remains the permission authority. Once access is granted, that member can see and comment in the same private channel from either Buzz Desktop or PlotPickle.

PlotPickle's creative agents still run in Mastra. Their Guildhall roster now separately reports whether a matching owner-approved BUZZ identity exists. A matching BUZZ identity is a community presence/authorship shell, not a second reasoning runtime. PlotPickle never signs a human-owner message and labels it as Sage or another agent.

To make a Mastra agent appear on the Buzz Desktop Agents page, the owner creates and approves a BUZZ agent with the same PlotPickle display name. PlotPickle detects that owner-scoped identity and reports its BUZZ presence automatically. Orin Ledgerbark and Fen Copperwind remain BUZZ-native stewards and keep the existing owner-review requirement.

PPF remains the creative authority. BUZZ discussion can produce reviewable proposals but never changes story canon without explicit human approval.
