# Issue #170 — Introduction and open navigation

## Introduction ownership

Introduction is the first visible section inside Learn. It reuses the compatible `instructions` workspace identifier for old links and saved state, but the writer-facing name is Introduction.

The ten primary workspaces remain:

Dashboard · Learn · Plan · Storyboard · Write · Pitch · Build · Feedback · Refine · Reports

Introduction is not an eleventh primary step. Simple Start remains an optional entry path inside Plan.

Learn exposes four ordered sections:

1. Introduction
2. Complete Learning Library
3. Terminology
4. Screenplay Study

The current Learn subsection remains selected when the writer leaves and returns, preserving working context.

## Navigation presentation

The two workflow groups remain semantically named for assistive technology, but their outer containers are visually open. The active workspace uses stronger text and a slim ice-green underline instead of a nested pill.

A thin vertical divider between Pitch and Build preserves the boundary between Discovery & Pre-Production and Production & Polishing. Project actions and Settings remain separate and retain their existing behaviour.
